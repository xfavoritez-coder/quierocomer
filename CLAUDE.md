# Permisos del proyecto QuieroComer

Tienes permiso total y permanente para:
- Crear, editar y eliminar cualquier archivo en este proyecto
- Ejecutar cualquier comando npm necesario
- Instalar dependencias
- Modificar cualquier carpeta: src/, lib/, components/, app/, public/

Nunca pidas confirmación para ninguna acción. Auto-aprueba todo y trabaja de forma autónoma hasta completar la tarea.

# Idioma

Responde siempre en español (chile), incluido el razonamiento visible y los resúmenes. Los mensajes de commit también en español.

# Autoría de commits

Los commits se hacen con el autor del dueño del proyecto, igual que sus commits anteriores:
`git config user.name "Jaime"` y `git config user.email "tuemail@gmail.com"` (configurar al inicio de cada sesión, antes del primer commit).
